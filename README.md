# 75michelle

Live at https://mmcghee18.github.io/75-michelle/

## Run locally

```sh
npm install
npm run dev
```

## Build & deploy

GitHub Pages serves the `docs/` folder on `main`.

```sh
npm run build   # writes the static site to docs/
git add -A
git commit -m "Update site"
git push
```

The live site updates a minute or two after the push.
